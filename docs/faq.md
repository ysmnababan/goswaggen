# FAQ & Troubleshooting

### Why isn't anything being generated?
- Make sure you're pointing to the correct main folder.
- Ensure your handler functions are **exported** and attached to a receiver (e.g., `func (c *UserController)`).
- Make sure your handler is registered in main.go and the name matches.
- Only `.go` files are processed — files with build tags may be skipped.

### Can I customize the generated annotations?
Yes, only for the error and success response. You can costumize this by changing the `goswaggen.yaml` file
generated by the `goswaggen init` command.

### Does it support frameworks other than Echo?
Currently supports:
- Echo (`echo.Context`)

We’ll consider Gin, Chi or Fiber if demand grows.

### I already have comments. Will they be overwritten?
Only if you use the flag `-f` or `--force`. If it is not, then the comment will directly written to CLI.

### Can I undo the changes?
Use version control! Always `git commit` before running the tool, or use `--dry-run` to inspect.

### Why comment is not inserted?
Use the -f flag to force direct insertion above the handler.

### Why goswaggen is not recognized?
Ensure $GOPATH/bin is in your system PATH after installation.
